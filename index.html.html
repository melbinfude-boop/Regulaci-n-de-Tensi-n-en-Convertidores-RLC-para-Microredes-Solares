1. Contexto industrial y arquitectura de control

En una microred solar, los paneles fotovoltaicos entregan una tensión que cambia con la irradiancia y la temperatura. Un convertidor CC-CC tipo reductor (buck) la baja al nivel del bus de carga y un filtro RLC de salida (inductor L con su resistencia serie RL, capacitor C y la carga R) suaviza el rizado de la conmutación. Si la carga cambia o las nubes pasan, la tensión del bus se desvía: el lazo de control debe mantenerla en su valor de referencia.

Elemento del lazoEn este sistema
PlantaFiltro RLC de salida con la carga resistiva R. Variables: corriente del inductor iL(t) y tensión del capacitor vC(t).
Sensor (transductor)Divisor resistivo con acondicionamiento (o sensor de tensión aislado) que mide vC y la lleva al ADC del microcontrolador.
ControladorCompensador PI digital: u = Kp·e + Ki∫e dt, con e = Vref − vC.
ActuadorModulador PWM y puente de MOSFET: convierte u en la tensión promedio aplicada al filtro.
PerturbacionesCambios de carga (R), variaciones de la tensión de entrada por irradiancia y temperatura, y resistencia parásita RL que crece con el calentamiento.

2. Modelado matemático físico

El convertidor se modela por su valor promedio: el actuador aplica una tensión u(t) al filtro. Es un sistema lineal, así que no requiere linealización por serie de Taylor. Si se incluyera la conmutación, el modelo promediado depende del ciclo de trabajo D y de Vin y sí habría que linealizar alrededor de (x0, u0); aquí se trabaja sobre el modelo ya promediado.

Ley de tensiones de Kirchhoff (malla del inductor)

u(t) = L·diL/dt + RL·iL + vC

Ley de corrientes de Kirchhoff (nodo de salida)

iL = C·dvC/dt + vC/R

Variables de estado

Se toma x = [iL, vC]T, entrada u y salida y = vC. Se despeja cada derivada:

diL/dt = −(RL/L)·iL − (1/L)·vC + (1/L)·u
dvC/dt = (1/C)·iL − (1/(RC))·vC
A = [ −RL/L   −1/L ;  1/C   −1/(RC) ],   B = [ 1/L ; 0 ],   C = [ 0   1 ],   D = 0

Función de transferencia

Con G(s) = C(sI − A)−1B + D, el determinante es det(sI − A) = (s + RL/L)(s + 1/(RC)) + 1/(LC), y el numerador sale de la entrada B y la salida C:

G(s) = VC(s)/U(s) = (1/LC) / [ s² + (RL/L + 1/(RC))·s + (1 + RL/R)/(LC) ]

Parámetros que se identifican: ω0 = √[(1+RL/R)/(LC)], ζ = (RL/L + 1/(RC)) / (2ω0) y ganancia en continua G(0) = R/(R + RL).

Valores base del proyecto: L = 470 µH, C = 100 µF, R = 10 Ω, RL = 0,1 Ω y Vref = 24 V (entrada de 48 V con D = 0,5).

Lazo cerrado con compensador PI

Con C(s) = Kp + Ki/s y realimentación unitaria negativa, y definiendo g = 1/(LC), a = RL/L + 1/(RC) y b = (1 + RL/R)/(LC):

T(s) = (Kps + Ki)·g / [ s³ + a·s² + (b + Kpg)·s + Kig ]

4. Simulador interactivo y validación en GNU Octave

Mueve los controles: la respuesta al escalón de Vref se recalcula en lazo abierto (escalón aplicado directamente a la planta) y en lazo cerrado con el PI. Se integra el modelo en variables de estado (Runge-Kutta de cuarto orden) y los polos se calculan de los polinomios característicos.

Script de GNU Octave

pkg load control
% Convertidor RLC (buck) - Regulación de tensión en microredes solares
L = 470e-6; C = 100e-6; R = 10; RL = 0.1; Vref = 24;

A = [-RL/L, -1/L; 1/C, -1/(R*C)];
B = [1/L; 0];  Cm = [0 1];  D = 0;
sis = ss(A, B, Cm, D);
G   = tf(sis)                         % G(s) = C(sI-A)^-1 B + D

disp('Polos lazo abierto:'), p_ol = pole(G)
disp('Valores propios de A:'), eig(A)
disp('Ceros:'), z = zero(G)
w0   = sqrt(1/(L*C)*(1+RL/R))
zeta = (RL/L + 1/(R*C)) / (2*w0)
Vss_ol = Vref * dcgain(G)             % Teorema del valor final, lazo abierto

Kp = 1; Ki = 1000;
Cpi = tf([Kp Ki], [1 0]);
T   = feedback(Cpi*G, 1);
disp('Polos lazo cerrado:'), p_cl = pole(T)
Vss_cl = Vref * dcgain(T)             % debe ser Vref por el integrador

t = linspace(0, 0.02, 2000);
[yo, ~] = step(Vref*G, t);
[yc, ~] = step(Vref*T, t);
figure; plot(t*1e3, yo, 'b--', t*1e3, yc, 'r', t*1e3, Vref*ones(size(t)), 'k:');
xlabel('t (ms)'); ylabel('v_C (V)'); grid on;
legend('Lazo abierto', 'Lazo cerrado PI', 'Referencia');
title('Respuesta al escalón del convertidor RLC');
print -dpng octave_escalon.png

figure;
plot(real(p_ol), imag(p_ol), 'bx', 'markersize', 12, 'linewidth', 2); hold on;
plot(real(p_cl), imag(p_cl), 'rs', 'markersize', 10, 'linewidth', 2);
grid on; xlabel('Re (rad/s)'); ylabel('Im (rad/s)');
legend('Polos lazo abierto', 'Polos lazo cerrado PI');
title('Mapa de polos (ceros: ninguno)');

Interpretación física

El filtro RLC solo, en lazo abierto, oscila al recibir un escalón porque casi no tiene pérdidas: el único amortiguamiento viene de RL y de la carga. Una carga más ligera (R mayor) reduce ζ y aumenta el sobreimpulso. Con una ganancia proporcional sola, el lazo cerrado baja el valor final (queda un error constante); con la acción integral el error en régimen permanente se anula y la regulación se mantiene ante cambios de carga, que se ven en el simulador al activar la perturbación.

Conclusiones

1) El modelo de segundo orden captura la dinámica esencial del filtro y se verifica por tres vías: matrices de estado, Mason y Octave. 2) El lazo cerrado con PI elimina el error estático y rechaza la perturbación de carga, a costa de añadir un tercer polo; Ki demasiado alto desestabiliza el sistema. 3) El diseño real debe considerar la saturación del PWM (0 a Vin), el retardo de muestreo y las pérdidas de conmutación, que este modelo lineal promediado no incluye.
